## 先说结论

Claude Pro 官网月付 $20，年付 $200/年。

国内自己订阅的话，理论上就是 $20 乘以汇率，大概 145 块上下。但实际难点不在汇率，在支付，很多人的银行卡直接就付不了。

我这边[代开](https://www.jrjrz.com/blog/claude-pro-zenme-kaitong/)目前 155 元/月，用的是你自己的 Claude 账号，一次开一个月。

如果你是第一次买，我的建议是先 Pro，不要直接上 Max。普通写作、聊天、偶尔写代码，Pro 就够了。高频 Claude Code 再考虑 Max。

我自己主要拿 Claude 写文章、日常聊天，还有用 Claude Design。说真的，写内容这块我觉得 Claude 确实比较聪明，设计感也不错，而且我这个使用强度下 Pro 额度一直够用。

## Claude Pro 官方定价多少钱？

月付 $20，年付 $200。

![Claude Pro 官方定价截图](https://pub-f83f8ab72bd843c1aa01040a49d20ad8.r2.dev/blog/claude-pro-duoshao-qian/img-1.png)

这是美国列表价，不含税。年付的话，$200/年，折下来大概 $17 一个月。本来按月付是 $20 × 12 = $240，年付直接砍到 $200，相当于打了个八三折。

我自己的判断，如果你已经确定会长期用 Claude，年付肯定更划算。但如果你是第一次订，我更建议月付一个月试试再说。

Claude 跟 ChatGPT 的使用感受差距还挺大的，有人用了觉得太好了再也回不去，也有人觉得不太习惯。先月付感受一下，比直接锁一年稳妥得多。

顺便说一下，Claude Pro 不含 API 用量。如果你需要调 API 做开发，那是单独开通、单独计费的，跟 Pro 订阅没关系。

## 为什么代开是 155 元，不是直接按汇率算？

这个问题蛮正常的。$20 按汇率算也就 140 左右，代开 155，多出来的十几块到底是什么？

坦率的讲，如果你自己有可用的海外支付方式，而且熟悉 Claude 的订阅流程，那自己开肯定最省。没必要找任何第三方。

代开的价值不是把 $20「变便宜」，恰恰相反，它比官网贵。

多出来的钱买的是省事。

什么样的人适合自己开？支付条件具备，熟悉海外订阅，遇到问题愿意自己折腾。

什么样的人适合代开？国内支付搞不定，不想研究各种教程，就想把账号发过去搞定收工。

我不是在试图证明 155 比官网便宜，因为它确实就是更贵。我只是把这件事讲清楚，多出来那十几块，买的是一个不用折腾的服务。这个逻辑本身没什么需要遮掩的。

Claude 个人版一共三个档位，

![Claude 个人套餐对比](https://pub-f83f8ab72bd843c1aa01040a49d20ad8.r2.dev/blog/claude-pro-duoshao-qian/img-2.png)


| 套餐    | 官方月费 | 年付    | 适合谁                         |
| ------- | -------- | ------- | ------------------------------ |
| Pro     | $20/月   | $200/年 | 大多数个人用户                 |
| Max 5x  | $100/月  | 无      | 高频使用，较高强度 Claude Code |
| Max 20x | $200/月  | 无      | Claude 是你的核心生产工具      |

Max 只有月付，没有年付打折。

其实吧，这三个档位的功能面高度重合。Pro 有的东西，Max 基本都有。Pro 已经包含 Claude Code、Claude Cowork、Claude Design、Claude Science、Research、无限 Projects 这些了，Max 不是另起炉灶搞了一套新功能。

那 Max 比 Pro 多买的是什么？

一个是额度。Claude 的用量是按每 5 小时一个 session 来算的，Max 5x 就是每个 session 里的额度是 Pro 的 5 倍，20x 就是 20 倍。

另一个是Fable 5的使用，Claude Pro 订阅是不包含 Fable 5的。

还有就是新功能和新模型会更早体验到。

所以你可以理解为，Max 不是一个完全不同的产品，它就是 Pro 加大杯。功能一样，额度更多。

我专门写了一篇文章是关于 Pro 和 Max 到底有什么详细区别。

## Claude Pro、Max 5x、Max 20x，我建议怎么买？

### 普通用户，先买 Claude Pro

写作、聊天、处理内容、Claude Design、偶尔写个代码，

这些场景，Pro 就够了。

我自己日常拿 Claude 写文章、聊天和做 Claude Design，这个使用强度下并没有遇到 Pro 额度不够用的问题。

我说的不是官方那句「Pro is suitable for everyday productivity」的客套话，是我自己掏了钱在用之后的实际感受。

### 偶尔写代码？还是 Claude Pro

这个可能跟很多人直觉不太一样。

不是说你是程序员就得上 Max。如果你只是偶尔让 Claude 帮忙 Debug 一下、写个脚本、改改代码，没必要因为「我是程序员」就直接拉满配置。

Pro 已经包含 Claude Code 了。偶尔用用的话，额度是够的。

### 高频 Claude Code，Max 5x

如果你每天有较长时间在编码，经常跑 Claude Code，而且 Pro 的额度已经开始影响你的工作节奏了，

这个时候再上 5x。

你想想看，如果是「已经影响了」，不是「我觉得可能会不够」。先用 Pro，真不够了再升，随时都可以。

### 预算够 + Claude 是主力工具，Max 20x

说一句可能有点直白的话，

如果 $200 的月费会让你犹豫很久，那大概率你还不需要 Max 20x。

真正需要 20x 的人，通常是额度不够造成的生产力损失已经远超 $200 了。这笔钱对他们来说根本不需要纠结。

先 Pro。

## 国内用户购买前，我认为必须知道的账号风险

我自己其中一个 Claude Pro 账号，在开通正常使用大概 5 天左右，被封了。之后申诉也没回来。。。

封号这个风险是真实存在的，我觉得你在付费之前应该知道。

这也是为什么我的 Claude Pro 代开，只对「订阅本身提前失效」提供对应处理。如果是 Claude 官方直接封禁了你的账号，不在订阅售后范围。

可能有人觉得这个售后条件对买家不太友好。

我理解这种感受。但我觉得把这件事提前说清楚，比跟你拍胸脯保证「100% 稳定，绝对安全」要靠谱得多。你想想看，如果一个代开商跟你说「绝不会封号」，你反而应该多留个心眼。

真实情况就是，Claude 的封号机制对国内用户存在不确定性。你得在了解这个风险的前提下做决定。

## 常见问题

**Claude Pro 可以用国内信用卡买吗？**

大概率不行。如果你手上有 Visa 或者 Mastercard 的全币种信用卡，可以先试试，试不了再考虑代开。

**Claude Pro 一个月多少钱人民币？**

官网 $20，按汇率大约 140 元左右（汇率实时浮动，以你付款时为准）。代开 155 元/月，续费约 153 元/月。

**Claude Pro 和 Max 最大区别是什么？**

一句话，额度。Max 的功能跟 Pro 几乎一模一样，多买的是 5 倍或 20 倍的使用额度，还有更高的输出上限。如果你 Pro 用着经常额度不够，再考虑 Max。不然 Pro 就够。

**程序员一定要买 Max 吗？**

不一定。偶尔写代码 Pro 就够了。只有高频、每天长时间跑 Claude Code 的场景才需要考虑 Max。

**Claude Pro 被封号可以退款吗？**

要分两种情况。如果是「订阅提前失效」，比如还没到期但订阅状态出了问题，这个可以按剩余天数处理。但如果是「Claude 官方封号」，属于平台行为，不在订阅售后范围。购买前请确认你了解这个风险。
